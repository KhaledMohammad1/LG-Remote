# تطبيق LG Magic Remote لنظام أندرويد 📱📺
مخصص لشاشات **LG Smart TV webOS 6.5.3** (موديل **LG 50UP7550PVG**) ومتوافق تماماً مع هاتف **Redmi A3**.

---

## 🌟 المميزات المدمجة بالتطبيق:

1. **الماوس السحري (Magic Remote Touchpad)**:
   - سطح لمس سريع وسلس لنقل مؤشر الماوس على الشاشة (`type:move`).
   - نقرة سريعة للضغط واختيار العناصر (`type:click`).
   - شريط جانبي مخصص لعجلة التمرير (`type:scroll`) لتصفح المواقع والقوائم بسلاسة.
   - إمكانية ضبط حساسية وسرعة المؤشر من السلايدر.

2. **مشغّل التطبيقات (App Launcher)**:
   - جلب قائمة البرامج المثبتة تلقائياً من الشاشة عبر (`listLaunchPoints`).
   - تشغيل أي تطبيق بلمسة واحدة (YouTube, Netflix, Shahid VIP, Web Browser, Live TV, وغيرها).

3. **لوحة التحكم بالريموت (Full Remote)**:
   - أزرار تعلية وتوطية وكتم الصوت (Volume Up / Down / Mute).
   - أزرار تقليب القنوات (Channel Up / Down).
   - أسهم الاتجاهات (D-Pad) وزر OK في المنتصف وزر العودة (Back) والصفحة الرئيسية (Home).
   - أزرار الميديا (Play / Pause).
   - الأزرار الملونة الأربعة (Red, Green, Yellow, Blue).
   - زر التبديل بين المداخل (HDMI 1, HDMI 2, AV).

4. **تشغيل الشاشة وإغلاقها**:
   - إغلاق الشاشة برمجياً (`system/turnOff`).
   - تشغيل الشاشة وهي مغلقة عبر تقنية **Wake-on-LAN (WOL)** باستخدام عنوان الـ MAC.

5. **نظام الاقتران الذكي وحفظ المفتاح**:
   - عند أول اتصال تظهر رسالة على الشاشة "Connection Request"، بمجرد الموافقة يحفظ التطبيق الـ `client-key` في `SharedPreferences` ولا يطلب الموافقة مرة أخرى.

---

## 🚀 كيفية فتح المشروع وتثبيته على الهاتف (Redmi A3):

1. **فك الضغط** عن ملف المشروع `LGRemoteApp.zip`.
2. افتح برنامج **Android Studio** واختر **Open** ثم حدد مجلد المشروع `LGRemoteApp`.
3. انتظر ثوانٍ حتى ينتهي **Gradle Sync**.
4. وصل هاتفك **Redmi A3** بالكمبيوتر عبر كابل USB مع تفعيل **USB Debugging** (تصحيح أخطاء USB).
5. اضغط على زر **Run (▶)** لتثبيت التطبيق على الهاتف مباشرة.

---

## ⚙️ إعدادات هامة في شاشة LG للتأكد من عمل الريموت:
في شاشة **LG 50UP7550PVG** (webOS 6.5.3):
1. تأكد أن الهاتف والشاشة متصلان بنفس شبكة الواي فاي (Wi-Fi).
2. افتح إعدادات الشاشة (**Settings**) > **جميع الإعدادات (All Settings)**:
   - اذهب إلى **الاتصال (Connection)** > **إدارة الأجهزة (Device Connection)** أو **تطبيقات LG Connect (LG Connect Apps)** وتأكد من تفعيلها (**On**).
   - اذهب إلى **عام (General)** > **الأجهزة الخارجية (External Devices)** > **التشغيل عبر Wi-Fi (Turn on via Wi-Fi)** وفعّلها إذا أردت تشغيل الشاشة عبر التطبيق وهي مطفأة.
